# battle_monster

Pokémon Survivor Burst (Pokémon Essentials 21.1) y su versión para transmisiones de TikTok LIVE.

- **Juego de escritorio**: `Game.exe` (RPG Maker XP + mkxp-z). Incluye un modo torneo para TikTok que se conecta con `live/bridge`.
- **Juego para TikTok LIVE**: carpeta [`live/`](live/README.md). Juego web vertical conectado a TikFinity que usa los sprites, datos, efectos y sonidos de este repositorio.

Análisis de la fusión y decisiones técnicas: [`live/docs/ANALISIS.md`](live/docs/ANALISIS.md).
